# C4 Editor

Десктопный редактор C4-диаграмм на Kotlin + Java (JavaFX).

## Запуск

```bash
./gradlew run      # запустить приложение
./gradlew test     # тесты логики редактора
```

Нужен JDK 25+. Проекты сохраняются в `~/.c4editor/projects/*.json` (автосохранение).

Кнопки «Экспорт…» и «Импорт…» на стартовом экране переносят проекты между компьютерами. Экспортированный файл
называется по имени проекта (`Интернет-магазин.json`). Импорт уже существующего проекта создаёт копию, а не
перезаписывает его.

## Как пользоваться

- **Контекст.** Добавляйте пользователей и системы кнопками панели и перетаскивайте их мышью.
  Щелчок по системе делает её *документируемой* (синей). Документируемая система может быть только одна.
  Флажок «Показать все элементы» включён по умолчанию; если его снять, на диаграмме остаются только
  документируемая система, связанные с ней элементы и её связи.
- **Связи.** Выберите «Связь» или «Пунктирная связь», затем щёлкните источник и цель. Подпись, тип линии
  и направление меняются в панели справа.
- **Контейнеры.** Двойной щелчок по документируемой системе открывает её диаграмму контейнеров.
  Сюда переносятся только те пользователи и системы, которые связаны с документируемой на диаграмме
  контекста. С ними можно соединяться, но добавлять и удалять их можно только на уровне контекста. Щелчок по контейнеру делает его
  *выбранным* (тёмно-синим); при снятом флажке «Показать все элементы» остаются только он, связанные
  с ним элементы, его связи и группы, в которых они лежат. Контейнер, перетащенный в группу, становится
  её частью и перемещается вместе с ней. Размер группы меняется за правый нижний угол.
- **Компоненты.** Двойной щелчок по контейнеру открывает его диаграмму компонентов. Сюда попадают
  элементы, связанные с контейнером на диаграмме контейнеров: с ними можно соединяться, но добавлять
  и удалять контейнеры, системы и пользователей здесь нельзя. Добавлять можно компоненты, хранилища
  данных и брокеры сообщений. Щелчок по компоненту делает его выбранным (тёмно-синим); при снятом
  флажке «Показать все элементы» остаются только он и связанные с ним элементы.
- **Код.** Двойной щелчок по компоненту открывает диаграмму кода — UML в синтаксисе
  [PlantUML](https://plantuml.com/ru/class-diagram): слева текст, справа картинка, которая
  перерисовывается при вводе. Отрисовку делает библиотека PlantUML (вариант под лицензией MIT).
  Если Graphviz не установлен, используется встроенный движок раскладки Smetana.
- При открытии проекта и переходе между уровнями диаграмма автоматически масштабируется (не крупнее 100%)
  и центрируется так, чтобы все элементы помещались на экране. Вписать заново — кнопка «Вписать в экран»
  или `Cmd`/`Ctrl` + `Shift` + `0`.
- `Cmd`/`Ctrl` + `+` / `-` масштабирует канвас, `Cmd`/`Ctrl` + `0` возвращает масштаб 100%.
- `Delete` удаляет выбранное, `Esc` отменяет инструмент или снимает выделение.

## Структура

| Путь | Назначение |
|---|---|
| `model/Model.kt` | Элементы, связи, раскладки по диаграммам, проект |
| `model/DiagramLevel.kt` | Уровни C4: палитра, видимость, переход «вглубь» |
| `editor/EditorController.kt` | Состояние и операции редактора (без JavaFX, покрыт тестами) |
| `ui/*` | JavaFX: список проектов, редактор, канвас, панель свойств |
| `java/.../render/*` | Геометрия фигур C4 и стрелок, отрисовка PlantUML (Java) |
| `storage/ProjectRepository.kt` | Сохранение в JSON |

## Уровни

Уровни описаны в `model/DiagramLevel.kt`: `ContextLevel` → `ContainerLevel` → `ComponentLevel` → `CodeLevel`.
Каждый уровень задаёт палитру, набор элементов, фокус (документируемая система, выбранный контейнер,
выбранный компонент), что можно удалять и куда ведёт двойной щелчок. У `CodeLevel` нет канваса
(`hasCanvas = false`): вместо него `ui/CodeDiagramView.kt` с текстом PlantUML, который хранится в
`Project.codeDiagrams`. Отрисовка PlantUML — `render/PlantUmlRenderer.java`.
